⚠️ **Beta Release** - This version is for testing purposes only.

## What's New in This Beta

### ✨ Workspaces
- Automatically save confirmed XY and Z changes to your current workspace.
- Undo and redo coordinate changes, with separate saved history for each workspace.
- Rename workspaces and export or import known-good coordinate backups.

### 🔧 Switching
- Switch directly from the toolbar and see which workspace is current.
- Save outgoing coordinates, skip unchanged offsets, and verify the new coordinates before completing a switch.
- Keep Manage available for inspecting saved coordinates and history.
